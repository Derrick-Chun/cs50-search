# CS50W Project 0 – Search

This is my submission for CS50 Web Programming with Python and JavaScript, Project 0: Search.

The goal of this project was to recreate the front-end of three types of Google search pages:  
- **Google Search**
- **Google Image Search**
- **Google Advanced Search**

I focused on keeping the design layout clean and functional while making sure the links, forms, and button actions behaved like the real thing. It was a good exercise in using HTML and CSS to build responsive pages, as well as understanding form submissions and GET requests.

This project was built without using any JavaScript.

Feel free to check out the code and try it locally!
